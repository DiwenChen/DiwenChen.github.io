Student App

Spring Semester 2024

In my freshmen year Software Engineering class, I developed a project application app in a team of four students.
-- The app was written in python and utillizes flask and SQLAlchemy.
-- It handles two user types: Faculty and Student.
-- Faculty can create project posts for students to join up.
-- Student could browse the catalogue and apply to interested projects.
The goal was to create a complete and smooth project application experience for all users.

App Showcase

The app was a beginner project for students to learn the basics of web development. It was my first web development project and first team development experience. I learned about user stories, iterative development cycle, update log, product backlog, UML, interface design, component-level design (Controller, Model, View), and much more. These knowledge served as cornerstones for all my future projects.
